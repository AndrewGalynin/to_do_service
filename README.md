# TODO List Service

A simple, yet functional To-Do list web application built with Django. This project was developed as a practice assignment to implement Class-Based Views (CBV), Many-to-Many relationships, and basic UI styling.

## 🚀 Features

* **Task Management:** Create, read, update, and delete tasks.
* **Tagging System:** Organize tasks by creating and assigning multiple tags.
* **Status Toggling:** Easily mark tasks as "Complete" or "Undo" them with a single click.
* **Smart Sorting:** Tasks are automatically ordered by status (Not done first) and creation date (newest first).
* **User-Friendly Forms:** Built-in HTML5 date-time picker for setting task deadlines.
* **Development Tools:** Integrated Django Debug Toolbar for monitoring database queries and performance.

## 🛠️ Technologies Used

* Python 3
* Django 
* HTML5 / CSS3 (Vanilla)
* SQLite (Default database)
* Django Debug Toolbar
